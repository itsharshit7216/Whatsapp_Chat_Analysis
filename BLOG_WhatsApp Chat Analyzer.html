Unveiling Your Texting Habits: Building a WhatsApp Chat Analyzer 📊📱

We all use WhatsApp daily to stay connected with friends, family, and colleagues. But have you ever stopped to wonder: Who actually talks the most in your group chat? What is your most frequently used emoji? Or what days are you most active?

I decided to turn those questions into a data science project.

I’m excited to share my latest project: the WhatsApp Chat Analyzer, a comprehensive web application built with Streamlit that analyzes and visualizes your exported WhatsApp chat data to give you fascinating insights into your texting habits.

🚀 Try the Live Demo here: WhatsApp Chat Analysis

🌟 Key Features & Visualizations

The application takes a simple exported .txt file from your WhatsApp and transforms it into a rich, interactive dashboard. Here is a breakdown of what you can discover:

1. Overall Statistics

Get an at-a-glance view of your chat’s footprint. The app instantly calculates the total number of messages, total word count, media shared, and links sent.

2. Activity Timelines

Want to see how your conversation has evolved over time? The app generates both Monthly and Daily timelines, allowing you to track message volume spikes (like during holidays or major events).

3. Activity Maps

Discover your communication patterns. The Activity Maps use bar charts and heatmaps to pinpoint your most active days of the week, the busiest months of the year, and even the exact hours you are most likely to be texting.

4. Busiest Users (Group Chats)

If you are analyzing a group chat, this feature is always a crowd-pleaser. It highlights who messages the most, complete with beautiful visualizations and data tables breaking down everyone’s percentage of contribution to the chat.

5. Word Clouds

Discover the most frequently used words by you and your friends. The app automatically filters out common stop words (like “the”, “and”, “is”) to give you a highly accurate visual representation of your most discussed topics.

6. Emoji Analysis

Because a picture is worth a thousand words! Get a detailed breakdown and a pie chart distribution of the emojis shared in the chat to see exactly what the overarching “vibe” of your conversation is.

📦 Under the Hood: The Tech Stack

To bring this project to life, I utilized a modern Python data stack:

  • Streamlit: For building the interactive web framework effortlessly.
  • Pandas: The backbone for all data manipulation and cleaning.
  • Matplotlib & Seaborn: For crafting the beautiful, informative data visualizations.
  • WordCloud: To generate the custom word cloud images.
  • urlextract: To parse and count the links shared in the chats.
  • emoji: For precise emoji parsing and extraction.

🛠️ How to Try It Yourself

Curious about your own chats? You can easily run this locally or use the live demo!

Exporting Your Chat

  1. Open the WhatsApp chat you want to analyze on your phone.
  2. Tap the three dots in the top right corner > More > Export chat.
  3. Choose Without Media.
  4. Save the generated .txt file to your computer.
  5. Upload the .txt file using the sidebar in the Streamlit app!

Local Setup

If you want to run the code on your own machine, follow these steps:

1. Clone the project

Navigate to the project directory containing app.py.

2. Install dependencies

Install the required Python packages using pip:

Bash

pip install -r requirements.txt

3. Run the application

Start the server using Streamlit:

Bash

python -m streamlit run app.py

After executing this command, your default web browser should automatically open and navigate to http://localhost:8501.
